You can create a free Redis Cloud https://cloud.redis.io/ subscription, which gives you a 30 MB database for learning and prototyping. Here’s a quick checklist:

Sign up or log in at the Redis Cloud console: Sign up here
Click "New Database" and select "Try 30 MB for free"
Choose your cloud provider (AWS, Google Cloud, or Azure) and region
Name your database and select the version
Click "Create database"
You can only have one free database per account. For detailed steps, see the official guide: Create a free database.
